## Summary

Implemented the `POST /v1/models/rescan` HTTP handler in `anvilml-server`. The handler
accepts a request, logs the trigger, spawns a tokio task that iterates over all configured
model directories and calls `ModelScanner::scan_dir()` for each, then immediately returns
HTTP 202 Accepted without blocking on scan completion. Two integration tests verify the
non-blocking contract and the observable results of the background scan.

## Deviations from Plan

1. **`ModelDirConfig` re-export**: The plan did not mention re-exporting `ModelDirConfig`
   from `anvilml-core`. However, the test code needs to construct `ModelDirConfig` values,
   and the type was not publicly re-exported at the crate root. Added `ModelDirConfig`
   to the `pub use` list in `crates/anvilml-core/src/lib.rs` to make it accessible to
   the integration test crate.

2. **`PathBuf` Display in tracing**: The plan's pseudocode used `path = %entry.path`
   in tracing macros, but `PathBuf` does not implement `Display`. Fixed by using
   `path = %entry.path.display()` in all tracing calls.

3. **Router clone in test**: The plan's test pseudocode used `router` after an initial
   `oneshot()` call, but `Router` does not implement `Copy`. Fixed by cloning the router
   before the first `oneshot()` call.

4. **`tokio::time::timeout` unwrap**: The `oneshot()` returns `Result<Response<Body>,
   Infallible>`. Added `.expect()` to unwrap the result before calling `.status()`.
